### 🔗 Email Delivery via the Resend HTTP API

Emails are now sent directly from the FastAPI backend via the Resend HTTP API — no n8n and no SMTP required.

  #### Email triggers

  1. Lead form submission (`POST /webhook`) → AI-drafted reply is emailed to the lead
     - Subject:  FantomAI | Lead Intake Proposal & Next Steps
     - Sender:    Fantom AI <team@fantomai.site>
  2. Appointment booking (`POST /api/appointments`) → confirmation email to the requester
     - Subject:  FantomAI | Genesis Session Confirmation
  3. Admin login → 2FA code email

  #### Configuration (.env / Render env vars)

    RESEND_API_KEY=<your Resend API key>   # starts with re_
    RESEND_FROM_EMAIL=team@fantomai.site
    RESEND_FROM_NAME='Fantom AI'
    CALENDAR_URL=https://cal.com/moaz-kashif-ovkhut/30min   # used in AI email replies

  Note: Resend requires a verified sending domain. Sending uses HTTPS
  (port 443) against api.resend.com — no SMTP host/port needed, which
  fixes the SMTP timeouts previously seen on Render. Zoho is still used
  for receiving inbound mail; only outbound sending goes through Resend.
