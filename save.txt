### 🔗 How to Connect Your n8n Workflow                                               
                                                                                        
  Here is how you can set up n8n to send the email using this project:                  
                                                                                        
  #### 1. In n8n: Configure the Webhook Trigger                                         
                                                                                        
  1. Add a Webhook node to your n8n workflow.                                           
  2. Set the HTTP Method to  POST .                                                     
  3. Copy the Production URL of your n8n Webhook.                                       
                                                                                        
  #### 2. In Your Dashboard: Link the URL                                               
                                                                                        
  1. Go to your Admin Dashboard: http://127.0.0.1:8000/.                                
  2. Click API Config in the left sidebar.                                              
  3. Paste your n8n URL into the n8n Webhook URL input box and click Save Configuration.
                                                                                        
  #### 3. In n8n: Configure the Email Node                                              
                                                                                        
  When a lead submits a form on your site, our server will analyze it and send this     
  structured JSON payload to n8n:                                                       
                                                                                        
    { 
      "name": "Arthur Dent",
      "email": "arthur@guide.com",
      "message": "We need an Excel automation...",
      "ai_analysis": {
        "urgency": "High",
        "category": "Inquiry",
        "summary": "Wants Excel form automation to save 4 hours of weekly work.",
        "draft_reply": "Dear Arthur, Thank you for reaching out to QuantumAI..."        
      }                                                                                 
    }   
      
  In your n8n email node (SMTP, Gmail, or Resend), set the following parameters
  dynamically using the incoming webhook data (fields are under `body`):

  • To:  {{ $json.body.to_email }}
  • Subject:  {{ $json.body.email_subject }}
  • Email Body:  {{ $json.body.email_html }}  (HTML draft from Gemini or smart fallback)      
  
  
  Website: http://localhost:8000/website 
  Dashboard: http://localhost:8000/
